# 🔐 User Authentication System (PHP & MySQL)

This project is a simple **User Authentication System** developed using **PHP, MySQL, JavaScript, HTML, and CSS**.  
It allows users to **sign up, log in, and log out securely**, making it suitable for academic projects and internships.

---

## 📌 Features

- User Registration (Signup)
- User Login with Session Handling
- Secure Logout
- Password storage using database
- Frontend validation using JavaScript
- Clean and responsive UI with CSS

---

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  
- **Package Management:** npm (package.json & package-lock.json)

---

## 📂 Project Structure
```
📁 project-folder
│
├── login.php # Handles user login
├── signup.php # Handles user registration
├── logout.php # Ends user session
├── script.js # Client-side validation & logic
├── styles.css # Styling for UI
├── users.sql # Database schema
├── package.json # Project dependencies
├── package-lock.json
└── README.md # Project documentation
```

---

## 🗄️ Database Setup

1. Open **phpMyAdmin**
2. Create a new database (e.g., `user_auth`)
3. Import the file: `users.sql`

4. Update database credentials in PHP files if required.
